# 共通戦闘・表示の改善（2026-11-24）

## 投射物

- 壁に当たった斧・コンパスが、衝突後もそのtickの速度で壁の中へ進んでいた問題を修正。壁の手前に止めて反射し、次のtickから戻ります。
- 手榴弾の跳ね返りも、衝突位置から移動を二重に適用しないよう統一しました。
- ロケット・火球は発射tickの手前の位置ではなく、実際の接触位置で爆発します。直撃した相手へのダメージは一度だけ処理し、味方保護と地形を壊さない仕様を維持します。
- 発射時の速度から向きを初期化。ナイフ・鉛筆などの飛行方向の角度をフレーム間で補間し、yawが±180度をまたいでも大回転しないようにしました。

## つかみ

AidenのペンチとDANGER Aliceの包帯は、攻撃線上の別の敵に当たっただけで本来の標的までつかんでいました。実際にダメージを受けた相手を確認してからつかむように修正しました。標的が避けたり無敵だったりした場合は、別の敵への命中だけで引き寄せません。

## 大きなエフェクト

予告リングや衝撃波は、中心にある0.5ブロックの箱だけで描画判定され、縁が見える位置でも中心が画面外になると全体が消えていました。表示専用の判定範囲を、リング半径・斬撃の傾き・棘の高さ・触手の揺れと拡大率に合わせました。当たり判定の大きさは変えていません。

## 検証と範囲

追加のGameTestは次の9件です。

`build` と `runGameTestServer` が成功し、既存の回帰テストを含む全29件を通過しました。

- 実際にロケットを壁へ飛ばし、爆発位置・近くの敵へのダメージ・味方保護・ブロック保持を確認。
- 火球の直撃接触位置、斧とコンパスの反射、手榴弾の跳ね返りを確認。
- ナイフの発射時の向きと、重力で角度が変わったtickの補間用角度を確認。
- ペンチの回避・包帯の命中失敗・ペンチの正常な成功を確認。
- 大きいリングの縁、傾いた斬撃、拡大した棘と触手が表示範囲内に収まり、物理的な当たり判定は拡大しないことを確認。

モデル形状・攻撃数・既存の陣営関係は今回変更していません。実クライアントでの操作・画面端の目視確認は未実施です。途中から描画範囲へ入ったキャラの攻撃アニメーション時刻や、一部のループアニメーションの端の姿勢差は、今後の改善候補として残っています。
